Microsoft is testing a built-in internet speed test in Windows 11 that reports download speed, upload speed and ping without sending users to a browser. The feature appears in Experimental Preview Build 26340.9767, released to Windows Insiders on Oct. 23. [1] [2]

## Several ways to start a test

Microsoft says Insiders can run the test from a new Speed test Quick Setting, from the Wi-Fi or Cellular flyout, or by right-clicking the network icon in the system tray and selecting “Test internet speed.” The interface shows progress and results against the active internet connection. [1] [2]

The update changes how the test is presented, rather than introducing a new measurement standard. Microsoft says results now stay within Windows instead of opening a browser. The company has not specified the test provider or methodology in the release notes, so users should not treat it as a replacement for a controlled network diagnostic. [2] [3]

## Gradual rollout to Insiders

The feature is listed under the Experimental channel release notes and is being rolled out gradually. Microsoft says controlled feature rollouts begin with a subset of Insiders and expand over time. The notes do not give a public-release date, and preview features can change or may never reach a general Windows release. [1] [2]

That distinction matters because the same announcement lists builds for multiple Insider channels, but the speed-test feature itself is marked for the Experimental release. Availability may therefore differ among people using the same broader Windows Insider program. [1] [2]

For now, the convenience is straightforward: users can get a quick reading of their current connection from the taskbar or Quick Settings. Microsoft has not promised broad availability or described how results compare with other speed-test services. [2]

## Why It Matters

Moving a speed test into Quick Settings removes a small but common reason to open a browser, and it keeps the result inside Windows. The feature is still an Experimental channel preview with no stated test provider or methodology, so it is a convenience rather than a controlled diagnostic. Insiders outside that rollout, and general Windows users, have no announced timeline for receiving it.
